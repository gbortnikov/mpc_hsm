## Middleware Chain

```
Request
   │
   ▼
┌──────────────┐
│   Recovery   │  Catches panics → Returns gRPC error
└──────┬───────┘
       │
       ▼
┌──────────────┐
│   Logging    │  Logs request/response + duration
└──────┬───────┘
       │
       ▼
┌──────────────┐
│     Auth     │  Validates mTLS + metadata
└──────┬───────┘
       │
       ▼
┌──────────────┐
│   Handler    │  Process the actual request
└──────┬───────┘
       │
       ▼
    Response
```
